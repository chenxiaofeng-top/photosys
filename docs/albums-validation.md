# 主题相册验证

验证日期：2026-11-19。

## 实现与兼容

- `library.sqlite` 增加 `albums` 与 `album_members`。相册 ID 自增且不复用，名称允许重复，成员通过相册 ID 与相对路径 BLOB 唯一对应。
- 读取旧库不建表；首次编辑在事务中建表，`user_version` 保持 0。仅有一张相册表或缺少所需列时报告结构错误，不按空相册处理。
- 同一文件可加入多个相册，重复加入幂等；创建并加入、批量加入、批量移出、改名及删除均使用事务。所有媒体编辑在提交前核对扫描 ID、文件 ID 与文件状态，失败整体回滚。
- 查询与编辑均使用现有数据库维护守卫，编辑还使用文件任务锁；整个提交期间持有当前媒体库会话，避免刷新后复用临时文件 ID。
- 文件缺失、改名或扫描后被替换时，不计入有效数量、封面和浏览结果；保留原路径关系，原路径文件恢复并刷新后可重新显示。
- 主题相册包含在现有 `library.sqlite` 快照备份中，备份与恢复增加两张表的兼容性检查，无需新增备份格式。
