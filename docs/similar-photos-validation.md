# 相似照片删除验证

验证日期：2026-11-19。

## 接口与行为

- 新增 `trash_similar({ scanId, groupId, fileIds })`，返回 `outcomes`、`totalGroups` 和 `affectedGroups`。逐项状态为 `moved`、`skipped` 或 `failed`，附相对路径和原因。
- `similar_groups` / `similar_members` 返回的照片新增 `hardLink` 字段；硬链接不可勾选。
- 删除成功后更新当前扫描结果；照片 ID 与未受影响组的 ID 保持稳定。删除代表图时，使用扫描时保存的特征重新匹配该组剩余照片，不再列出单张组。
- 扫描统计保留原值，仅相似组数量更新。媒体库需要手动刷新，缓存由下次扫描清理。

## 自动检查

- `npm run build`：Vue / TypeScript 检查和生产构建通过。构建仍有地图资源包体积提示。
- `cd src-tauri && cargo test --lib similar::tests`：22 项通过，2 项需要额外样本的性能测试忽略。其中新增 16 项删除测试，使用临时真实文件、文件身份校验和模拟回收站，不访问用户回收站。
- `cd src-tauri && cargo test --lib duplicates::tests`：10 项通过，1 项依赖独立桌面回收站环境的测试忽略。
- `git diff --check`：通过。

删除测试覆盖正常处理、无效及过期请求、整组删除拒绝、重复 ID、硬链接、文件缺失/改写/替换、根目录替换、符号链接、保留项变化、备用保留项、部分失败与重试、删除代表图后拆组/解散/重新分类，以及未受影响组和照片 ID 稳定性。

使用本地 Vite 页面，在独立浏览器上下文注入临时 Tauri IPC 模拟。模拟代码与示意预览仅在验证浏览器中生效，未加入应用代码。

- 代表图可勾选；硬链接禁选；每组至少保留一张。
- 28 张照片跨成员页保留勾选；切换组、匹配筛选、重新扫描时清空勾选。
- 确认弹窗列出跨页勾选的路径、目录、大小和保留数量，默认聚焦取消按钮；点击取消或 Escape 均不调用删除命令。
