# 人物与家庭时间线 · 分组设置填写说明

打开当前相册，在顶部点击 **「人物」**，展开 **「分组设置」**。第一次使用建议保留 **最低相似度 `0.65`、候选分差 `0.08`**。SFace 和 AuraFace 的默认值相同，自定义值按相册和人物模型分别保存。

## 两项参数怎么填

两个输入框都填小数，范围为 `0 ≤ 数值 < 1`。相似度是模型算出的匹配分数。

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| **最低相似度** | `0.65` | 人脸与得分最高的组代表至少达到这个分数，才有机会归到该组。 |
| **候选分差** | `0.08` | 有两个候选组时，第一名至少要领先这么多。并列第一的人脸会显示在「未成组的人脸」。 |

例如，人脸与两个组代表的相似度分别为 `0.77` 和 `0.71`，只相差 `0.06`。使用默认候选分差时，这张人脸会留在「未成组的人脸」，由你判断。

## 遇到什么情况该调哪项

下表的数值是从默认值出发的试调示例。每次改一项，保存后在「待整理」里查看分组效果。

| 情况 | 最低相似度 | 候选分差 | 试调目的 |
| --- | --- | --- | --- |
| 刚开始整理，先看分组效果 | `0.65` | `0.08` | 从默认值开始。 |
| 外貌相似的家人经常被混到同一组 | `0.65` | `0.10` | 要求第一名更明显地领先第二名。 |
| 整体误归较多，想提高匹配门槛 | `0.70` | `0.08` | 提高最高分的要求。 |
| 同一人的侧脸、旧照经常漏归，想扩大匹配范围 | `0.62` | `0.08` | 试着接纳更多低分匹配，查看原照片核对人脸。 |

已归错的人脸，可在人物详情的「修改分组 / 管理人物与人脸」中移入正确人物或移回待整理。同一个人已有多个手动创建的人物时，可用「合并人物」处理。

## 保存和整理

1. 点击 **「保存参数」**，然后打开 **「待整理」** 查看重新计算的相似人脸组。
2. 打开一组，逐张勾选或点击 **「全选本组」**。全选跨页，可以取消个别勾选。使用 **「查看原照片」** 核对。
3. 点击 **「新建人物并归入」** 或选择已有的人物后点击 **「移入此人物」**。归属可以整批撤销。
4. 如需恢复模型默认值，点击 **「恢复默认值」**，再点击 **「保存参数」**。

- **「分组设置」没出现，或无法保存、确认**。先确认已打开相册，并在「人物模型设置」中查看当前模型。SFace 和 AuraFace 支持自动分组。相册为只读时，保存和确认按钮会禁用。
