## 浏览器验证

使用现有 Vite 页面与临时 Tauri IPC 模拟数据；模拟只注入测试浏览器，没有添加到应用代码或生产包。图片来自本机 GNOME 壁纸，仅用于检查比例、旋转和预览，不代表真实相册内容。

- 已查看 1440×1024、1024×768、800×600、390×844 的界面；五个页面在四种尺寸、两套主题下的 40 个布局状态均未发现横向溢出，覆盖完整侧栏、图标侧栏、展开式导航、长路径和长文件名。
- 已验证手动主题在重载后恢复、跟随系统实时切换，以及减少动态效果时过渡缩短为 0.01ms；窄窗口中收起导航后焦点回到菜单按钮，选中页面后焦点转到主要内容。
- 抽查正文、辅助文字、强调文字、状态提示和实色按钮共 11 组文字/背景组合；浅色最低对比度为 4.66:1，深色最低为 5.75:1，不含禁用控件。
- 已检查网格、详情并排/上下布局、旋转、左右切换、跨页预览、关闭后的焦点恢复、搜索无结果及清除筛选、收藏和分页。
- 已检查人物列表、个人时间线、默认收起的模型设置、AI 设置展开、空相册、只读提示、扫描失败与重试。
- 已检查归档进度与结果、目录带入、任务进行时导航禁用；任务过程中切换主题未产生新 IPC 请求，未重启或取消任务。
- 已检查重复文件结果、自动勾选、回收站确认与取消默认焦点；取消没有调用删除命令。已检查相似照片结果与并排选择。
- 已检查备份恢复弹窗、备份清单、覆盖提示、危险按钮及双主题下的弹层颜色。
- 已检查地图切换主题后保持同一地图实例、中心、缩放与位置范围选择，底图和标记颜色变化，没有重新请求相册数据。

## 仍需在 Tauri 桌面运行环境验收

浏览器模拟验证不能证明原生文件、媒体解码和数据库操作成功。以下应在可丢弃的测试相册中执行，不要将模拟结果视作真实文件操作验收：

1. 打开、刷新、更换真实相册，验证原生目录选择与只读相册行为。
2. 验证 JPG、HEIC、视频和实况照片的实际预览、播放、收藏与方向保存；重启后核对数据。
3. 验证模型安装/切换、后台索引、停止与重试，以及人物命名、合并、人脸纠错和撤销。
4. 验证真实归档复制、重复文件移入系统回收站及相似照片扫描。
5. 验证数据库备份、恢复、失败回滚与恢复后重新读取；确认原文件保留。
6. 验证实际离线街道地图包、地图点位、框选及本机 WebView 中的主题切换。

本次仅调整前端界面、主题状态与地图展示，不修改 Rust 命令或数据库结构。
